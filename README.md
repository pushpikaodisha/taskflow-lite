# TaskFlow Kanban

> Multi-Column Kanban Workflow Tracker

![PHP 8+](https://img.shields.io/badge/PHP_8%2B-1e293b?style=flat-square) ![SQLite (PDO)](https://img.shields.io/badge/SQLite_(PDO)-1e293b?style=flat-square) ![Bootstrap 5](https://img.shields.io/badge/Bootstrap_5-1e293b?style=flat-square) ![4-Column Kanban Grid](https://img.shields.io/badge/4--Column_Kanban_Grid-1e293b?style=flat-square) ![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

## 📌 Executive Overview
Responsive PHP 8+ and SQLite Kanban board organizing tasks across Todo, In Progress, Review, and Done columns with priority badges and modal creation.

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pushpikaodisha/taskflow-lite.git
   cd taskflow-lite
   ```

2. **Launch locally:**
   Run `php -S localhost:8000` and open `http://localhost:8000/`.
